# Bundled fonts

The app embeds two open-source fonts to match the TermKrush brand (see the
landing page / design mockup):

- **Space Mono** — body / UI text. © The Space Mono Project Authors.
  SIL Open Font License 1.1 — see `SpaceMono-OFL.txt`.
- **Bungee** — display face for the wordmark + section headers. © David Jonathan Ross.
  SIL Open Font License 1.1 — see `Bungee-OFL.txt`.

Both are OFL 1.1, which permits bundling in the binary. Source:
<https://github.com/google/fonts>.
