## Goal
Select what you operate by pressing a NUMBER, not Tab/arrows.

## Spec
- `1`–`8` select the matching pad; `0` selects the timeline. The number is shown on each panel's border.
- `Esc` from a pad or the timeline returns to the Library (home base).
- Replaces Tab/Shift-Tab + arrow focus-movement for picking a pad/timeline.

## Open
- Within a selected pad/timeline, keep the existing actions (Space play, Enter menu/edit, etc.)? Assume yes unless the PM says otherwise.
