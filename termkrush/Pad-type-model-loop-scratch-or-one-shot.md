## Problem
Pads need a type — loop, scratch, or one-shot — that determines their controls and playback.

## Acceptance
- [ ] Each pad carries a type (loop / scratch / one-shot) with a sensible default.
- [ ] Assigning a track sets/keeps the pad type; the cell shows it.
- [ ] The type is cyclable on the focused pad.
