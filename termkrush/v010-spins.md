## Release v0.1.0 — "spins"

First usable release. The minimum bar to put termkrush in front of a user.

### Contents
- Two-deck TUI with focus and transport.
- Local mp3 crate browser.
- cpal output, symphonia decode.
- Per-deck volume, master, linear crossfader.
- Offline BPM detection with cache.
- Pitch-preserving time-stretch + tempo nudge.
- Sync deck-to-deck.
- Manual cue point per deck.
- Auto-fade transition.
- GitHub Pages landing page, README, MIT license.
- Cross-platform binaries (mac arm64/amd64, linux arm64/amd64, win amd64).
